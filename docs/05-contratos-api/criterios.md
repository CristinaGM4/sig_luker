# Contratos REST

Cada operación debe documentar método, ruta, finalidad, credencial, permisos y ámbito, parámetros, esquemas, validaciones, errores y aceptación. Definir paginación, límites, tipos de contenido, errores consistentes y reglas de idempotencia según el flujo. Al acordar la primera operación, crear OpenAPI 3.x, Swagger y la colección Postman con entorno de prueba sin secretos. Controlar visibilidad de la documentación según despliegue.
