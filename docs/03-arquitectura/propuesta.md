# Arquitectura propuesta

Monolito modular en Node.js y TypeScript. Un despliegue y una base facilitan transacciones, pruebas y operación inicial. Considerar procesos de trabajo separados cuando el aislamiento de fallos, la concurrencia o los tiempos de importación observados lo justifiquen.

- Núcleo de identidad, autorización, auditoría, instituciones y periodos. IBITE depende del núcleo; histórico y puntuación dependen de IBITE. MTTS, factibilidad y matriz conservan sus casos de uso. Intervenciones dependen del protocolo. Fichas, histórico y SIG comparten infraestructura de importación con validadores específicos. Analítica y reportes consumen consultas de lectura autorizadas.
- NestJS con adaptador Express como propuesta inicial. Módulos, inyección, guards, validadores y Swagger aportan convenciones comunes; Express directo reduce estructura inicial y exige acordar esas convenciones en el equipo. Fastify directo ofrece validación por esquema y alto rendimiento con mayor responsabilidad de organización; como adaptador Nest conserva sus módulos, con integración multipart distinta. Reevaluar tras validar dependencias y medir cargas. [Adaptadores NestJS](https://docs.nestjs.com/techniques/performance)
- Controladores delgados, casos de uso para transacciones y políticas de dominio explícitas. Repositorios para Prisma y consultas espaciales. API REST versionada, DTO con validación estricta y contrato OpenAPI previo a la implementación.
- PostgreSQL con Prisma para persistencia relacional y PostGIS para geometrías y consultas. La documentación de Prisma 8 incluye geometrías y predicados tipados mediante extensión; versiones previas documentan limitaciones de campos Unsupported. Cobertura de tipos, índices y operadores, madurez del paquete, permisos de extensión y compatibilidad de migraciones requieren una prueba con versiones concretas en la fase autorizada. Usar SQL versionado para DDL sin cobertura y consultas parametrizadas encapsuladas donde haga falta. [Prisma 8 PostGIS](https://www.prisma.io/docs/orm/extensions/postgis) · [Prisma 7 y extensiones SQL](https://www.prisma.io/docs/orm/v7/prisma-schema/data-model/unsupported-database-features)
- Sesión revocable de servidor como primera opción para Angular y API bajo el mismo sitio. Si se aprueba, usar cookie HttpOnly, Secure y protección CSRF. La topología, recuperación y emisión de credenciales se validan antes del contrato. El ámbito se comprueba en el servidor para cada consulta y operación.
- Archivos en almacenamiento privado con metadatos y estados en PostgreSQL. Límites de tamaño y expansión, verificación de formato, validación previa a publicación y transacciones. Docker Compose para base de desarrollo y base desechable de pruebas si el equipo confirma disponibilidad. Semillas sintéticas, configuración validada, ESLint y Prettier. Verificar versiones estables y compatibilidad antes de instalar.
